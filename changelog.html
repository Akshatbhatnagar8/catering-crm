Weddings & Events
Managing your sales pipeline
The pipeline tracks every enquiry from first contact through to completed event. Each client moves through stages as the sale progresses.
➕
Adding a new client
1
Tap + New Client in the top right.
2
Fill in the client name, phone, email, and which agent referred them.
3
Go to the Events tab and add each event — select the type (Wedding, Mehendi, Haldi, etc.), date, and expected headcount. For anything not in the list, choose Other and type the name.
4
Add an Est. Value (IDR mn) — this feeds the revenue bars and summary totals.
5
Close the card — it saves automatically.
🔄
Moving clients through stages

Open the client card and change the Stage dropdown. The pipeline has these stages in order:

Lead from Agent → Tasting Scheduled → Tasting Completed → Sample Menu Sent → Menu Finalization → Awaiting Confirmation → Confirmed → Completed

Cards highlighted in red have been in their stage too long. Cards with a yellow border have a reminder due today.

Tip: Once an event has happened, move the client to Completed. This shifts their value from the Confirmed bucket to the Completed bucket in the summary bar.
⏰
Setting a follow-up reminder
1
Open the client card and go to the Reminder tab.
2
Set a date, add a note about what needs to happen, and assign it to a team member.
3
This automatically creates a task in that person's Todo list.
📁
Uploading files

Open the client card → Files tab → tap Upload File. You can attach menus, invoices, proposals — anything up to 25 MB. Files can be previewed in the browser or downloaded.

Weddings & Events
Deposit Tracker New
Switch to the Deposits tab (next to Pipeline and Monthly) to see all confirmed and completed events with their payment status.
💰
Recording a deposit
1
Go to Deposits view from the header.
2
Find the client in the table. Type the deposit amount (in IDR mn) in the Deposit Received column.
3
Set the date the deposit was received and add a note if needed (e.g. "Bank transfer received").
4
The Balance and Status columns update instantly. It saves automatically.
Status labels: Awaiting = no deposit yet · Partial = deposit received but balance outstanding · Paid in Full = fully paid.
📊
Reading the summary

At the top of the Deposits view you'll see four numbers: Total Confirmed Value (what you're owed across all confirmed events), Deposits Received (what's come in so far), Outstanding (what's still owed), and the number of clients.

Weddings & Events
Monthly view New
Switch to Monthly to see the next 12 months as columns, with each client grouped by their event date and a revenue bar showing progress against the IDR 600mn monthly target.
📅
Navigating months

Use ‹ Back and Forward › to move by 12 months at a time. Tap Today to snap back to the current window. Scroll left and right inside the columns to see all 12 months.

📊
Reading the revenue bar

Each month column has a coloured bar showing progress toward IDR 600mn:

Blue = Completed (event has happened, revenue delivered)
Green = Confirmed (signed, upcoming)
Yellow = Pipeline (still in progress, not yet confirmed)

The label below shows the breakdown, e.g. IDR 450mn / 600mn · 200 done · 250 conf.

Todo Lists
Team task board
Each person has their own column. Tasks are sorted with urgent items at the top and recurring tasks at the bottom, separated by a divider.
➕
Adding a task
1
Type the task in the box at the top of the person's column.
2
Set the priority (High / Med / Low), category, and due date.
3
For tasks that repeat, set the Recurring dropdown to Daily, Weekly, or Monthly — the task will automatically reopen after the period ends.
4
Tap + Add or press Enter to save.
⭐ Big Rocks: Tick the star checkbox to mark a task as a Big Rock — important, high-priority work. These appear at the top of the column in their own section.
✅
Completing and managing tasks

Tick the checkbox to mark a task done. An Undo bar appears for 8 seconds if you ticked it by mistake. Tasks done more than 7 days ago move to the archive — tap Show archived at the bottom of the column to see them.

Tasks highlighted in amber are more than 7 days old and haven't been completed — time to act or remove them.

🔍
Views and search

Active — all open tasks across the whole team.
Due Today — only tasks with today's date, across all people.
Last Week — tasks completed in the last 7 days. Useful for standups.

The search bar at the top filters across all columns instantly.

🔁
Recurring task separator

Each column now shows a — Recurring — line separating one-off tasks (above) from repeating ones (below). New tasks always land above the line so they're easy to spot.

Travel Agents & ODC
Group bookings tracker
Track group bookings and outdoor catering across all three venues. Switch between a calendar view and a list view.
➕
Adding a booking
1
Tap + New Booking and fill in the agent name, venue, date, and pax count.
2
For venues not in the list, select Other and type the venue name.
3
Add a status note — e.g. "Deposit received", "Pending menu", "Confirmed".
🗓
Calendar vs list view

Calendar — shows the current month in a grid. Tap any day to see bookings. Use the arrows to move between months.

List — shows all bookings in date order. Toggle Show all months to see past and future bookings beyond the current month.

Platform
Bulk import via Excel New
Use this when you have a list of new clients to add all at once — faster than entering them one by one.
📋
How to use the import template
1
Go to Import Template from the home screen and tap Download Excel Template.
2
Open the file in Excel or Numbers. Fill in one row per event. The Stage and Event Type columns have dropdowns — use them to avoid spelling mistakes.
3
If a client has multiple events (e.g. Wedding + Mehendi), add one row per event and repeat the client name exactly in each row.
4
Save the file and upload it back on the same page — drag and drop or click to select. A preview table shows what will be added.
5
Tap Add to Pipeline to confirm. Clients appear in the pipeline immediately.
Date format: Always use DD MM YYYY with spaces — e.g. 15 11 2026. Est. Value is just the number — 1.5 means IDR 1.5mn.
